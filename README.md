# SUMMIT España v0.8

Prototipo web para senderismo en España. Mapa interactivo, búsqueda de lugares, cimas y refugios desde OpenStreetMap, importación y exportación GPX, seguimiento GPS experimental, rutas guardadas y carga de GeoJSON.

## Publicación
En GitHub: Settings → Pages → Deploy from a branch → main / root.

## Limitaciones
El mapa base y Leaflet dependen de servicios externos; el GeoJSON guardado puede visualizarse sin fondo, pero la navegación completamente offline no está garantizada. No se garantiza GPS con pantalla bloqueada. La aplicación no sustituye herramientas de seguridad en montaña.
